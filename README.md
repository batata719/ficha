# Tá Jóia RPG

## Instalação no celular

O app pode ser instalado como PWA pelo menu do navegador (“Adicionar à tela inicial” ou “Instalar app”). Depois do primeiro acesso online, a interface e os arquivos principais ficam disponíveis offline. O livro de regras fica disponível offline depois de ser aberto ao menos uma vez.

O service worker exige HTTPS (ou `localhost` durante o desenvolvimento). Ao publicar em um subcaminho, mantenha os caminhos relativos do manifesto e do service worker.
